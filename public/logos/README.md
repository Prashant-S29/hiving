# Logos

Every model in `data/seed-models.ts` currently points `org_logo_url` at
`placeholder.svg`. Before launch, replace each with a real logo sourced from the
organization's official press kit or brand page, and log the source (URL + license)
in a `logo_sources.json` in this folder so usage stays defensible — this was flagged
as a requirement in `files/models-schema.json`.
